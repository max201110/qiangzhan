NEON BREACH / 霓虹突围
Release 1.0.0 - Windows x64
Build date: 2026-09-05
Engine: Unity 6000.0.62f1

启动：双击 NeonBreach.exe；或在项目目录双击 Play-Game.cmd 通过 conda base 启动。
标题界面点击 DEPLOY TO SECTOR 07。

操作：WASD 移动 | 鼠标视角 | 鼠标左键射击 | 左 Alt 瞄准 | R 换弹
左 Shift 冲刺 | Space 跳跃 | Esc 暂停 | M 静音

包含：Windows x64 独立版本、5 波战斗、FPS 移动/射击/瞄准/换弹/冲刺/跳跃、掩体寻路、补给、HUD、小地图、设置和最高分保存。
请保留整个文件夹，不要只复制 exe。
